# Срок

Браузерный фанатский клон дворовой VK-социалки **2012–13** (энергия, ходки, крыша 8ч, рейды с корешами). Свой арт и кликухи. Не связан со студией Кефир.

Папка `tyuryaga/` в корне репозитория Ta4ka. Flutter-приложение не трогали.

## Локально

```bash
cd tyuryaga
npm install
npm run dev
```

Открой http://127.0.0.1:5173/

Сборка: `npm run build` (статика в `dist/`).

Сейв — `localStorage` ключ `srok-v1`. Сброс: Анкетка → «Сбросить хату».

**Хата 5D (не картинка):** после «В хату» ты внутри камеры от первого лица. WASD — ходить, мышь — смотреть (клик по комнате захватывает курсор), E — взять, C — сесть на нары/табурет. Из хаты выходишь в коридор и во двор ногами, не по иконке-обоям. На телефоне — стик слева.

По умолчанию **темп ×60** (1 энергия / 5 сек, крыша и окно рейда сжаты), иначе классика неиграбельна в одной сессии. ×1 — как в 2012: 1 энергия / 5 мин, 8 часов на крышу и босса.

Клик по шкале энергии — перемотать +1 час локально.

## Известные дыры vs оригинал

- Название и NPC свои (Срок, Шило, Толян, Плита…), не каталог Кефира.
- Нет SWF-арта, шансона, озвучки, трёх полосок, звёзд на плечах, celebrity-боссов.
- Каталог наколок короче; ночь открывается с 16, не ~100.
- Лагеря / повязки / меняла — заглушка.
- Москва и побег — прогресс-бары, не отдельная карта.
- Зарубы — счётчик ударов, не арена.
- Подогревы и рейды на локальных ботах, не VK-друзьях.
- Таланты — 7 узлов, не платное дерево на тысячи голосов.
- Чифир за локальные «голоса», не VK.
- Telegram-wiki цифры **не** смешивались: энергия зон из таблиц 2011–13.
